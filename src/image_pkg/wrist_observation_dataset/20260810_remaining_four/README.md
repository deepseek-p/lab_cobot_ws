# 2026-08-10 腕部相机观察位采样

本目录由 `station_cruise` 在 `home → tooling_zone → aging_zone → station_b → home` 的实际 Gazebo 巡航中生成。每张图与 `manifest.jsonl` 的同名记录对应，记录源图像时间戳、YOLO 同步结果、目标框像素大小和居中判定。

本轮四张 `base_view` 图均**未包含其目标物体**，YOLO 同步框也为空。因此它们只能作为腕部相机的背景/负样本；不得为目标类别创建正样本框，也不得用于声称补充了该物体的正样本训练数据。

在修正腕部光轴和 MoveIt 观察位后，应重新采集每类至少 50 张目标可见图：目标框不贴边、中心落在图像中间 50% 区域、覆盖不同距离/俯角/光照；随后人工标注真实边界框，再并入训练集。
